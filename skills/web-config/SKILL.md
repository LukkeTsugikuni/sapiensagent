# Web Config

Keep the WebUI opt-in; never launch a browser implicitly. Use a responsive dashboard with navigation, forms, validation, status, logs, providers, channels, scheduler, skills, permissions, media, and resource controls. Reuse the gateway configuration API, show ready/optional/disabled states, and visually inspect loading, empty, error, success, and narrow-window states. Keep dependencies small and avoid embedding secrets in markup or logs.
