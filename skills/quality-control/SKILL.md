# Quality Control

Run focused tests during iteration and the full suite before release: format, tests, clippy with warnings denied, release build, launcher smoke tests from an unrelated directory, and Playwright CLI checks for the WebUI. Inspect generated visual artifacts. Test failures, missing providers, disabled features, bad config, cancellation, and secret redaction—not only happy paths.
