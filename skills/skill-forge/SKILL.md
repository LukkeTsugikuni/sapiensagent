# Skill Forge

Use observed task history to detect meaningful repetition, deduplicate candidates, and generate a real skill folder containing `SKILL.md`, metadata, tests, and examples only when justified. Keep automatic selection enabled, default new skills to local scope, classify permissions and risk, test before registration, create a backup, and support disable, remove, and rollback. Never grant external-write, destructive, secret-input, or network permissions implicitly.
