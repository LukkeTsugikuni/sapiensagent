# Release Engineer

Verify clean status, build metadata, release binary, checksums, installer dry-run, and global invocation before release. Keep temporary/build artifacts ignored, preserve user changes, create an informative commit, and report exact limitations. Do not force-push or overwrite an existing remote history without explicit authorization.
